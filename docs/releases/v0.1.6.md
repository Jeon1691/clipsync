# ClipSync v0.1.6

Released 2026-09-17 (UTC).

- Uses the operating system's certificate verifier for both HTTPS requests and
  secure WebSocket connections to the relay.
- Adds `CLIPSYNC_CA_FILE` for a PEM bundle of additional trusted private CA
  certificates, with errors for unreadable or empty bundles.
- Adds TLS verifier and configured CA-file information to `clipsync doctor`.

Upgrade impact: certificate acceptance now follows OS trust policy. Private-CA
deployments should configure their trusted root in the OS trust store or supply
the CA bundle through `CLIPSYNC_CA_FILE`. Certificate verification remains
enabled; inspect `clipsync doctor` if connection behavior changes.
