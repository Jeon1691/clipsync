# ClipSync v0.1.10

Released 2026-09-17 (UTC).

- Adds a Windows x86_64 CLI ZIP, Windows clipboard text/image access, background
  pairing, and local daemon communication through named pipes.
- Registers Windows background synchronization in the user's Startup folder.
- Adds Linux desktop-session autostart and passes graphical-session environment
  variables into the systemd user service for clipboard access after login.

Upgrade impact: Windows users can extract `clipsync.exe` from the release ZIP,
place it on `PATH`, and create or join a room. Windows file-list clipboard
support is not included in this version. Existing Linux installations should
run `clipsync daemon restart` from their graphical login session to refresh the
service and autostart configuration.
