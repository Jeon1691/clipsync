# ClipSync v0.1.7

Released 2026-09-17 (UTC).

- Removes routine macOS `launchctl` output when creating, replacing, or stopping
  the background service, and uses bootstrap/kickstart with a fallback to load.
- Explains unknown or expired pairing codes and directs users to create a fresh
  code on the other device.

Upgrade impact: pairing and service setup produce less macOS service-manager
noise. If a pairing code is rejected as unknown or expired, run
`clipsync room create` on the originating device and use its new code.
