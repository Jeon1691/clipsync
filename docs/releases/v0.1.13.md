# ClipSync v0.1.13

Released 2026-09-22 (UTC).

- Adds a source-built desktop window for creating/joining rooms and checking
  background-sync status on macOS, Linux, and Windows. Run it from this tag with
  `cargo run -p clipsync-desktop`; published archives remain CLI packages.
- Adds the Windows PowerShell installer and local winget-manifest installation
  path. Fixes Windows background pairing inheriting console output handles.
- Improves Linux text fallback when clipboard contents are not a file URI, and
  reduces unnecessary reconnects after short runtime stalls.
- Bounds incoming transfer state and image-decoder allocation, expires old
  incomplete transfers, validates transfer IDs before creating inbox paths, and
  rejects duplicate or unsafe filenames, including Windows device names.

Upgrade impact: restart the daemon after replacing the CLI. Incoming transfers
with newly rejected names or identifiers fail instead of being staged; rename
files that use reserved names or trailing dots/spaces before sending. Images
that exceed the decoder's allocation limit can also be rejected. The checked-in
winget manifests still target v0.1.12. To install this release with the new
script, run `./scripts/install-windows.ps1 -Version 0.1.13` from this tag's
checkout. The tag adds local-manifest support; availability in the winget
community repository was not established by this change.
