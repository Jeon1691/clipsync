# ClipSync v0.1.14

Released 2026-09-23 (UTC).

- Updates macOS file pasteboard publishing so Finder can copy received files
  into the folder that has focus when the user pastes.
- Makes received images available as staged files for Finder/Desktop paste
  while also exposing image data to apps that accept PNG/TIFF.
- Preserves original image bytes when reading those staged images back, so the
  sync loop recognizes them as images instead of new file transfers.
- Reads macOS filename-list clipboard data as well as file URLs and prefers
  copied files over their preview bitmap.

Upgrade impact: restart the daemon to load the updated macOS clipboard behavior.
Received image data can now be written to a private `pasteboard` directory under
the ClipSync data directory for file-style pasting; it is not stored only in the
OS clipboard. Pasting into Finder uses the destination folder focused at paste
time. Images continue to expose PNG/TIFF representations for other applications.
