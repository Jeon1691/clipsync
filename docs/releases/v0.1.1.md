# ClipSync v0.1.1

Released 2026-09-16 (UTC).

- Allows one-shot `clipsync pull --wait` to receive chunked image and file
  transfers, in addition to text.
- Flushes the printed pairing code promptly, including when command output is
  captured by another process.
- Adds a Linux arm64 CLI archive alongside the existing macOS and Linux x86_64
  archives.

Upgrade impact: for a manual image or file transfer, start the receiving
`clipsync pull --wait` before pushing from the sender; binary transfers are
online-only. Room creation still waits in the foreground in this version.
