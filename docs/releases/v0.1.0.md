# ClipSync v0.1.0

Released 2026-09-16 (UTC).

- First public CLI release for pairing devices and sending encrypted clipboard
  content through a WebSocket relay. Commands cover room creation/joining,
  manual push/pull, synchronization, and daemon control.
- Provides prebuilt CLI archives for macOS Apple Silicon, macOS Intel, and
  Linux x86_64, with Homebrew installation instructions.
- Includes relay source and Docker deployment configuration for self-hosting.
  Linux credentials use private local files without requiring a D-Bus keyring.

Upgrade impact: this is the initial release. Run `clipsync init` before creating
or joining a room. Use the documented HTTPS relay or configure TLS for a
self-hosted relay. Images and files require the receiving device to be online.
