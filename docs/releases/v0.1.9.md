# ClipSync v0.1.9

Released 2026-09-17 (UTC).

- Fixes macOS login-service registration so replacing a LaunchAgent does not
  leave it disabled for the next login, and refines restart behavior.
- Uses the Homebrew prefix executable for service registration when available,
  avoiding a path tied to a particular version in the Cellar.
- Preserves home, executable search path, and optional custom home/CA settings
  in macOS and Linux service definitions. Linux services restart automatically.
- Adds `login_service` to `clipsync doctor` output.

Upgrade impact: after installing this version, run `clipsync daemon restart`
once for an existing paired installation to rewrite its service registration.
Use `clipsync doctor` to inspect whether the login service is installed.
