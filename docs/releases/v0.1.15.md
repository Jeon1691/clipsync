# ClipSync v0.1.15

Dependency security fixes and verifiable release downloads.

## Changes

- Update Rust dependencies to fix the rustls, Tokio, rustix, quick-xml, and Quinn
  advisories identified during the security review. Replace the deprecated PEM
  parser with rustls's supported API. See the [security review](https://github.com/Jeon1691/clipsync/blob/v0.1.15/docs/security-alerts.md)
  for advisory identifiers and the remaining upstream maintenance warnings.
- Include signed build-provenance bundles alongside release archives and verify
  them during the release workflow. Consumers can verify the downloaded archive
  using the [release verification instructions](https://github.com/Jeon1691/clipsync/blob/v0.1.15/docs/packaging.md).
- Restore release builds on supported macOS runners. Keep the macOS, Linux,
  and Windows CLI archives and the existing supported GUI functionality.

## Upgrade impact

Upgrade installed clients to receive the dependency security fixes. Source
builds require Rust 1.88 or newer. The build-provenance bundles are new release
assets; existing unsigned archives are not retroactively attributed to the new
build workflow. Review the verification instructions before relying on a
downloaded archive.

The project still has six visible upstream unmaintained-package advisories.
They are tracked separately from patched-version vulnerabilities and are not
suppressed by the audit configuration.
