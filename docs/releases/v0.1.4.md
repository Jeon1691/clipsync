# ClipSync v0.1.4

Released 2026-09-17 (UTC).

- Reports background pairing startup failures with the recorded error or useful
  worker-log details instead of only reporting that the worker exited.
- Separates the Unix background pairing worker from the terminal's process
  group and makes it ignore hangup signals.
- Retries a failed pairing WebSocket connection once and adds relay/WebSocket
  context to connection errors.

Upgrade impact: this release targets unsuccessful or interrupted background
pairing. Retry room creation after installing it and use the reported connection
details to diagnose relay failures; an unsuccessful attempt does not establish
a paired room.
