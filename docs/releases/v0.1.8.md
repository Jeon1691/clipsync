# ClipSync v0.1.8

Released 2026-09-17 (UTC).

- Creates the device identity automatically when first needed, including daemon
  startup, so a separate `clipsync init` is optional.
- Adds a Homebrew post-install initialization step and updates the quick-start
  flow to begin with `clipsync room create`.

Upgrade impact: first use or Homebrew installation can now create the local
identity and configuration. Existing explicit `clipsync init` commands remain
available; scripts should account for initialization happening before that step.
