# ClipSync v0.1.2

Released 2026-09-16 (UTC).

- Makes one-shot pushes wait for relay acceptance before sending content,
  reducing transfers lost during connection setup and surfacing relay errors.
- Extends `clipsync pull --output <dir>` to save text as `clipboard.txt` and
  images as `clipboard.png`, `clipboard.jpg`, or `clipboard.webp`, according to
  the received type.
- Adds a packaged Linux CLI smoke check to the release workflow.

Upgrade impact: scripts using `--output` can now create text and image output
files as well as received files. A push can wait for relay acceptance and report
a connection error instead of immediately attempting to send.
