# ClipSync v0.1.12

Released 2026-09-17 (UTC).

- Detects stale relay connections and sleep/wake clock jumps, sends WebSocket
  heartbeats, and retries initial reconnections more quickly. A failed send now
  ends the session so the daemon can reconnect.
- Adds the shared UniFFI mobile integration crate and documents the separate
  iOS and Android source repositories. The CLI release archives do not contain
  mobile apps.
- Changes this version's project license declaration and packaged license file
  from MIT OR Apache-2.0 to MIT.

Upgrade impact: restart the daemon to use the new connection watchdog,
particularly on machines that sleep between clipboard transfers. Integrators
should review the MIT license shipped with this version, the mobile-core build
instructions, and the newly added integration interfaces.
