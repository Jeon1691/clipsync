# ClipSync v0.1.3

Released 2026-09-16 (UTC).

- Changes `clipsync room create` to print a pairing code and return while a
  background worker waits for the joining device.
- Adds `--foreground` (also accepted as `--wait`) to keep pairing in the current
  terminal.
- Records pairing progress for `clipsync status` and prevents a second
  background creator from using the same local data directory while one waits.

Upgrade impact: command completion no longer means pairing has finished when
using the default room-creation mode. Scripts that need to wait for pairing
must use `clipsync room create --foreground` or inspect pairing status.
