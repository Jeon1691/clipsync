# ClipSync v0.1.5

Released 2026-09-17 (UTC).

- Enables native certificate roots for relay connections and macOS system
  configuration support for HTTP proxy settings.
- Includes underlying network/TLS error details in pairing failures and
  `clipsync doctor` output, making certificate and connection problems easier to
  identify.

Upgrade impact: relay HTTP requests can now use macOS system proxy settings and
system certificate roots. Check `clipsync doctor` when connecting through a
corporate network to inspect certificate or connection failures.
