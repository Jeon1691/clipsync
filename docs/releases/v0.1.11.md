# ClipSync v0.1.11

Released 2026-09-17 (UTC).

- Adds file-list read/write support to the Windows/generic clipboard adapter
  and uses native pasteboard file URLs on macOS, including multiple files.
- Improves image paste interoperability on macOS by publishing TIFF alongside
  PNG and percent-encodes special characters in file clipboard URIs.
- Waits for relay acceptance before the daemon begins synchronization and
  processes the initial peer state and queued text. Logs failures to write a
  received item to the local clipboard.

Upgrade impact: restart the daemon to use the updated clipboard adapters.
Clipboard file entries must refer to regular readable files; directories and
symlinks are not transferred by the native file-list path. This release improves
OS clipboard handling in addition to the manual file-transfer commands.
